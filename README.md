# Orbit Bloom

A circular-themed arena survivor for the browser, built for CrazyGames (SDK v3 integrated).

- 6 heroes rendered in real 3D (Three.js), 8 weapons, 8 passives, 8 monster types, 2 bosses, biomes
- Move: WASD / arrows / drag - Dash: Space - Pause: P - Mute: M

## Run
Open `index.html` (keep `three.min.js` next to it). For SDK testing use a local server, e.g. `npx serve`.

## Ship to CrazyGames
Zip `index.html` and `three.min.js` and upload via the Developer Portal.
